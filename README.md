# Floating To-Do (Windows)

A small translucent to-do list that floats on your desktop.

- Type in the box and press Enter (or +) to add an item
- 🗑 deletes an item
- Drag the header to move it
- ☰ (top-left) shrinks it to a ☰ bubble; click the bubble to expand (drag it to move)
- ⚙ has: Always on top, Start with Windows, Opacity
- ✕ closes it

Your list and settings are saved in `%APPDATA%\FloatingTodo\data.json`.
